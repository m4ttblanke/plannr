# Plannr Landing Page Design

## Goal

Explain Plannr visually and quickly:

Syllabus → extracted deadlines → reviewed events → organized calendar.

The page should make the manual setup Plannr removes immediately obvious.

## Current design status

To be audited before redesign.

## Core story

1. Syllabi contain the information students need.
2. Turning that information into a usable calendar is manual and repetitive.
3. Plannr extracts the important events.
4. The student reviews them before syncing.
5. Plannr keeps each class organized and can reconcile syllabus changes.

## Primary CTA

Join the Free Beta

Links to `go/beta.html`, which records a Cloudflare pageview and redirects to
Plannr's public TestFlight invitation. The beta is free — no payment step.

## Product proof

Prefer real Plannr screenshots and product UI over abstract illustrations.

## Trust

Communicate that users can review/edit extracted events before calendar sync.

## Motion

Use motion to explain transformation, not as decoration.

Respect prefers-reduced-motion.
