Everything the app does

Six things Plannr handles so you don't have to.

Upload a PDF, scan a printed copy, pick from Photos, or paste text. Plannr extracts every assignment, exam, quiz, and lab deadline automatically.
Each course gets its own secondary Google Calendar in the color you choose. Events are visually distinct across all your classes.
When a professor updates the syllabus, upload the new version. Plannr reconciles the changes and syncs only what's different.
Every sync session is saved. See exactly what events were pushed to your calendar and when, for every class.
A dashboard view shows everything due across all your classes this week so nothing slips through between courses.
PDF files, camera scans, photo library images, and plain text are all supported. If you can read it, Plannr can parse it.
